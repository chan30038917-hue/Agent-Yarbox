# Guía de Inicio Rápido (Quick Start)

Bienvenido a **AgentYarbox**, el notario on-chain para agentes autónomos en Monad.

## Requisitos previos
- Node.js (v18 o superior).
- Foundry instalado.
- Una wallet con MON en **Monad Mainnet** (Chain ID 143).

## Opción 1: SDK (Desarrolladores)

```bash
npm install @chan30/agent-yarbox
